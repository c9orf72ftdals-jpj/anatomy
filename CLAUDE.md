# Contexto del Proyecto: Tesis Final de Medicina Humana (Cohorte Retrospectiva)

- Este repositorio contiene el manuscrito completo de una tesis de investigación médica con diseño de **cohorte retrospectiva**.
- **Skill obligatorio:** Antes de auditar, corregir o editar cualquier archivo del manuscrito, carga y aplica íntegramente el protocolo `revisor-tesis-cohorte` ubicado en `.claude/skills/revisor-tesis-cohorte/SKILL.md`.
- **Integridad bibliográfica:** Usa exclusivamente el conector oficial **PubMed** (y los archivos locales del repositorio si existen) para verificar citas y metadatos. Está estrictamente prohibido inventar referencias, autores, PMIDs, DOIs o cifras.
- **Preservación de datos:** Al sugerir correcciones de redacción, nunca modifiques los valores numéricos ni los resultados reales del estudio; si detectas una inconsistencia aritmética entre texto y tablas, repórtala explícitamente para decisión del autor.
